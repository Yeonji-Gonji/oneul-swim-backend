# ADR-0003: DB 외부 백업은 GitHub Actions 가 age 로 암호화해 artifact 로 30일 보관한다

- 날짜: 2026-10-26
- 상태: 채택
- 관련: `.github/workflows/backup-offsite.yml`, `docs/OPERATIONS.md` §3

## 배경

일일 덤프(`scripts/backup.sh`)가 같은 서버 안(`~/oneul-swim-backups`, 7일)에만 있었다. 2026-10-26 오라클 콘솔이 MFA 기기 분실로 잠기고
이 기기에는 서버 SSH 키도 없어, 서버에 닿는 길이 GitHub Secrets 하나뿐인 상태가 드러났다. 그때 서버나 계정을 잃었다면 데이터도 함께 잃었다.

## 검토한 대안

1. OCI Object Storage(무료 20GB)에 서버 크론으로 업로드 — 설정이 단순하지만 오라클 계정이 잠기면 백업도 함께 막힌다.
2. 개인 맥의 launchd 가 주 1회 `scp` — 맥이 꺼져 있으면 건너뛰고, 기기 교체 때 끊긴다.
3. GitHub Actions 가 매일 서버 최신 덤프를 받아 age 공개키로 암호화해 artifact 로 30일 보관 — 오라클과 무관한 곳에 남고, 공개 리포여도
   암호문만 올라간다. 덤프가 오래됐으면 실패해 서버 백업 크론 감시도 겸한다. (채택)

## 결정

대안 3. 공개키는 리포 변수 `BACKUP_AGE_RECIPIENT`, 비밀키는 리포·서버에 두지 않고 사용자 비밀번호 관리자에 둔다.
서버 호스트 키 지문을 워크플로에 고정한다. 공개 리포라 Actions 분·artifact 저장은 무료다.

## 결과

- 비밀키를 잃으면 외부 사본은 열 수 없다. 비밀키 보관이 이 결정의 전제다.
- 서버를 재구축하면 호스트 키 지문(`HOST_KEY_FP`)을 갱신해야 워크플로가 다시 돈다.
- 되돌릴 경우의 비용: 워크플로 파일과 리포 변수를 지우면 끝난다.
